# Plugin ALSA -> PulseAudio/PipeWire (`pcm.type pulse`). Requis par le BANC PC
# x86 (conf/docker/x86/) pour atteindre un casque BLUETOOTH : le Bluetooth
# n'existe pas comme carte ALSA, il n'est servi que par PipeWire côté hôte —
# sans ce plugin, arecord/aplay -D <alias pulse> échouent sur "Unknown PCM".
# Neutre sur le Pi (il attaque ses cartes USB en hw direct, aucun serveur
# audio n'y tourne) : le paquet est présent mais jamais sollicité.
libasound2-plugins

# Build helper requis pour compiler le binding C de PyAudio contre portaudio
python3-dev

# Diagnostic caméra USB (v4l2-ctl) — la capture elle-même passe par opencv (pip)
v4l-utils

# Requis par opencv-contrib-python (non-headless), installé TRANSITIVEMENT
# par mediapipe (cf. conf/requirements.txt) : sans libgl1, `import cv2` échoue
# au chargement avec "libGL.so.1: cannot open shared object file" — piège
# classique de la variante non-headless d'opencv sur un système sans X11/GPU.
libgl1
