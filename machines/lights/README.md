# machines/lights

Lumières de scène : pas encore d'hôte ni de code. **À créer avec le gabarit d'appareil** :
`python3 packages/theatre_gabarit/tools/nouvel_appareil.py <nom>`, puis les gestes de
[`packages/theatre_gabarit/README.md`](../../packages/theatre_gabarit/README.md). Le nom
`lights` est refusé (c'est déjà le topic des lumières de scène, `topics.LIGHTS`) : en choisir un
autre (par exemple `lumieres`), ce dossier sera alors remplacé.
